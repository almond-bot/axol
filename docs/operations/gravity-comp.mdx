---
title: "Gravity Compensation"
description: "Make Axol's arms weightless so you can move them by hand."
---

Gravity compensation holds both arms weightless so you can move them by hand. The arms don't sag and don't spring back. Use it to pose the robot, check its range of motion or guide it by hand. Start it from the web control panel or with `axol gravity-comp`.

## Before you start

- Install Axol with the [one-command install](/installation) and power on the robot.
- Bring up CAN and check the motors. The control panel does this when it connects. On the CLI, run [`axol can.setup`](/cli/can-setup) once, then check a motor with [`axol motor.info`](/cli/motor-info).

<Warning>
  The arms go limp as soon as gravity compensation starts. Be ready to support them so they don't drop.
</Warning>

## Run it

<Tabs>
  <Tab title="Control Panel">
    <Steps>
      <Step title="Connect the robot">
        Connect the **Axol Host**. The panel connects the robot. If it doesn't, press **Connect** on the **Axol** tile. No cameras are needed. See [Connections](/guides/control-panel#connections).
      </Step>

      <Step title="Select Gravity compensation and Start">
        Pick **Gravity compensation** from the operation selector and press **Start**. The arms go weightless. Press **Stop** to hold them stiff again.

        To record what you do by hand, fill in **Record** before you start. The recording is saved when you stop. Press **Build motion** in the diagnostics dashboard to turn it into a [reference motion](/cli/motion-build) you can replay.
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    On the robot's computer:

    ```bash
    axol gravity-comp                                 # all 7 joints free, both arms
    axol gravity-comp --right_channel null            # left arm only
    axol gravity-comp --kd 1.0                        # heavier damping (less floppy)
    axol gravity-comp --free_joints [WRIST_3]         # only WRIST_3 free; the rest held rigid
    axol gravity-comp --record demo1                  # capture the hand-guided motion
    ```

    Press `Ctrl+C` to stop.

    - `--free_joints` frees only the joints you name. The rest of the arm holds its pose, so you can test one joint at a time.
    - `--record` saves the session so [`motion.build`](/cli/motion-build) can turn it into a reference motion.

    See [`gravity-comp`](/cli/gravity-comp) for every flag.
  </Tab>
</Tabs>

<Tip>
  If an arm sags or pushes back, adjust the per-joint `mass` and `com` fields on `AxolConfig`. See [Gravity compensation](/api/robot#gravity-compensation).
</Tip>
