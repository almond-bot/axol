---
title: "Marionette"
description: "Drive Axol's arms, grippers, lift and Jelly from one or two iPhones running Marionette."
---

Marionette turns an iPhone into a teleoperation controller. Each phone drives one arm and its gripper. Two phones drive both arms. A phone's **Drive** screen also drives Jelly and raises or lowers the lift.

The control panel's **Marionette** page shows the robot in 3D, every phone and all three cameras. From the page you can drive Jelly and the lift with the keyboard.

## Before you start

- Build the Marionette app onto each iPhone from a current copy of the Marionette repository. See its README.
- Install Node 22 or newer on a computer that the phones and the robot can both reach, and clone the Marionette repository there. This can be the robot's computer, a laptop on the same Wi-Fi, or a machine on the same Tailscale network.
- For cameras, assign the ZED cameras in **Axol settings → Cameras**. In sim, rendered head and wrist views are used instead.

## Start the gateway

In the Marionette repository, run:

```bash
npm install
npm run dev:axol
```

It listens on port 8787 and serves the Axol phone screen. Note the computer's address (for example `ipconfig getifaddr en0` on a Mac, `hostname -I` on Linux, or `tailscale ip -4`).

## Run it

<Steps>
  <Step title="Open the Marionette page">
    In the control panel, open **Marionette**. Type the gateway's address in **Gateway**, for example `192.168.1.20` or `localhost` when the gateway runs on the robot.
  </Step>

  <Step title="Start">
    Pick **Sim** or **Robot**, then press **Start sim** or **Start on robot**. The page shows when Axol has connected to the gateway.
  </Step>

  <Step title="Connect the phones">
    On each iPhone, open Marionette, type the gateway's address and tap **Connect**. Each phone appears on the page with its name and color.
  </Step>

  <Step title="Calibrate each phone">
    Stand facing the same way as Axol. On the phone, tap **Calibration**, then **Start calibration**, and follow the four steps. Forward on the phone is then forward for the robot.
  </Step>

  <Step title="Pick an arm and drive">
    On each phone, choose **Left** or **Right**. Hold the **Hold to move** pad and move the phone: the gripper follows, moving and turning the same way. Let go to stop. Press again to carry on from where the phone is now.
  </Step>
</Steps>

## Phone controls

The phone screen has two modes, **Arm** and **Drive**. **Left arm** / **Right arm**, the cameras and **Stop** show in both.

| Control | What it does |
|---|---|
| **Hold to move** | The arm follows the phone while you hold the pad. While holding, slide your thumb down to close the gripper and up to open it. |
| **Open gripper** / **Close gripper** | Open or close the gripper fully. |
| **Motion scale** | How far the gripper moves for each centimetre the phone moves. Start low. It is locked while you hold the pad. |
| Drive stick | In **Drive**, push the stick to drive Jelly. Jelly stops when you let go. |
| **Turn left** / **Turn right** | Turn Jelly while held. |
| **Raise lift** / **Lower lift** | Move the lift while held. |
| **Speed limit** | Top speed for driving and turning. |
| Camera views | Show the head camera, either wrist camera, both wrists or all three. |
| **Stop** | Stops the whole robot: both arms hold where they are, and Jelly and the lift stop. |

## Desktop keys

On the **Marionette** page, these keys drive Jelly and the lift:

| Key | Action |
|---|---|
| W / S | Drive forward / back |
| A / D | Drive left / right |
| Q / E | Turn left / right |
| Z / X | Raise / lower the lift |
| Esc | Turn **Stop motion** on |

## Safety

- On the robot, a phone must be calibrated before it can move an arm.
- The arm moves only while the phone's pad is held, its tracking is good and it is not calibrating. If anything drops out, or tracking jumps, the arm stops and waits for a new press.
- **Stop** on any phone, or **Stop motion** on the page, stops the whole robot. After you turn every Stop off, press each pad again to carry on.
- If a phone goes offline with **Stop** on, the robot stays stopped. Press **Clear Stop** on the page once it is safe.
- If two phones pick the same arm, the phone that moved it last keeps it. The other phone shows which phone has it.
- Jelly and the lift stop at once if the drive stick, a held button or the page stops sending.
- Press **Stop Marionette** to end the session. The arms return to rest before their motors turn off.
