Every setting for `axol collect-dagger`. Add any flag below to the command, or set it once in the control panel. See [Command configuration](/cli/configuration) for config files and syntax.

The [shared settings file](/guides/control-panel-settings) (`~/.almond/settings.json`) is read by default. It stores these flags in the same sections as for [data collection](/operations/data-collection-config), without this command's prefixes.

| Flag | Section in the settings file |
|---|---|
| `robot_config.axol_config.*` | `axol` |
| `robot_config.left_channel`, `robot_config.right_channel` | `robot` |
| Other `robot_config.*` fields | `lerobot` |
| `teleop_config.vr_teleop_config.*` | `teleop` |
| `teleop_config.kinematics_config.*` | `kinematics` |
| Recording flags | `recording` |

```bash
axol collect-dagger --policy_path myorg/pick-act --policy_type act \
  --repo_id myorg/pick-dagger --task "pick up the cup" \
  --robot_config.axol_config.left_stiffness 0.8
```

<Warning>
  Use the **same** stiffness, gripper torque, `observe_torques`, `observe_cartesian`, `fps` and cameras as when the policy's training data was recorded. A policy only works with the settings it was trained on.
</Warning>

## Policy

| Flag | Default | Description |
|---|---|---|
| `--policy_path` | required for local policies | Checkpoint, as a HuggingFace Hub repo ID or a local path. Not used with `custom`. |
| `--policy_type` | required | `act`, `smolvla`, `diffusion`, `tdmpc`, `vqbet`, `pi0`, `pi05`, `groot` or `custom` ([your own model](/operations/custom-policy)). |
| `--device` | `cuda` | `cuda`, `cpu` or `mps`. Local policies only. |
| `--episode_time_s` | `600` | Maximum episode length (s), including interventions. `0` removes the cap. |
| `--policy_max_vel` | `6.283` | Local policies: speed limit (rad/s) on joint actions. `0` turns it off. |
| `--policy_max_accel` | `21.99` | Local policies: acceleration limit (rad/s²) on joint actions. |
| `--subtasks` | `null` | Local policies: a list of instructions, such as `["reach","grasp","lift"]`. Type a number from 1 to N to switch instruction during an episode. Not allowed with `custom`. |

## Custom policy interface

These fields apply with `--policy_type custom`, which uses the [custom policy interface](/api/policy-plan). Set them on the `collect-dagger` command. DAgger reads its shared settings from data collection, not from the **Inference** settings that run policy uses.

| Flag | Default | Description |
|---|---|---|
| `--server_host` | `127.0.0.1` | Address of the existing policy endpoint. |
| `--server_port` | `8765` | Policy endpoint port. |
| `--actions_per_chunk` | `30` | Maximum number of actions in each plan. |
| `--plan_config.request_interval` | `5` | Run this many actions between policy requests. |
| `--plan_config.max_adoption_offset_steps` | `6` | How many control steps a reply may arrive after its request. Must be shorter than the plan. |
| `--plan_config.late_policy` | `blocking_refresh` | When the plan runs out, hold and request a new one. `abort` ends the session instead. |
| `--hold_to_intervene` | `false` | Must be `true` with `custom`. Hold a grip to take control, and release both to hand back. |
| `--shadow_inference` | `true` | Keep the policy predicting while you drive. Its replies are ignored. |
| `--handover_duration_s` | `0.2667` | Time (s) to blend from your last command back to the policy when you hand back. |
| `--record_joint_actions` | `false` | Record joint commands as the actions, whatever action layout the policy uses. |
| `--start_from_current_pose` | `false` | Skip the move to rest at startup and after teleoperating between episodes. |
| `--home_on_start` | `false` | With `--start_from_current_pose`, still move to rest at startup. |

## Recording

| Flag | Default | Description |
|---|---|---|
| `--repo_id` | required | Dataset ID, `<user>/<dataset>`. |
| `--task` | required | Task description saved with every frame and sent to local policies. A custom policy chooses instructions on its server. |
| `--fps` | `30` | Recording rate and control rate. Must match the policy's training rate. Cameras capture at 60 and drop frames to match. |
| `--teleop_hz` | `120` | Motor command rate (Hz) while you intervene, independent of `fps`. |
| `--policy_fps` | `20` | Rate of new camera images for the policy, up to the capture rate. Between images the policy reuses the last ones. Recording and control stay at `fps`. |
| `--dataset_resolution` | `SVGA` | Resolution of the recorded video and of the images the policy sees: `SVGA`, `HD1080` or `HD1200`. |
| `--vcodec` | per platform | Dataset video codec: `h264` on Jetson, `auto` elsewhere. |
| `--root` | `null` | Local dataset directory. Default is the LeRobot cache, `~/.cache/huggingface/lerobot`. |
| `--push_to_hub` | `false` | Upload the dataset to the HuggingFace Hub when done. Log in first. See [Upload to the HuggingFace Hub](/operations/data-collection#upload-to-the-huggingface-hub). |
| `--rerun_ip` | `null` (off) | Stream live visualisation to a [Rerun](https://rerun.io) viewer at this address. |
| `--rerun_port` | `9876` | Rerun viewer port. |
| `--log_level` | `INFO` | `DEBUG`, `INFO`, `WARNING`, or `ERROR`. |
| `--config_path` | none | Load a JSON or YAML config file. Flags override it. |
| `--settings_path` / `--no_settings` | `~/.almond/settings.json` | Read another [shared settings file](/cli/configuration#the-shared-settings-file), or ignore it. The config file and flags override it. |

## Teleoperator {#teleop-config}

| Flag | Default | Description |
|---|---|---|
| `--teleop_config.has_gripper` | `true` | Set automatically from `--robot_config.axol_config.has_gripper`. |
| `--teleop_config.vr_teleop_config.gripper` | `parallel` | Set automatically from `--robot_config.axol_config.gripper`. Box mode is available only with `parcel`. |
| `--teleop_config.id` | `null` | Used by LeRobot only. Axol ignores it. |
| `--teleop_config.calibration_dir` | `null` | Used by LeRobot only. Axol ignores it. |
