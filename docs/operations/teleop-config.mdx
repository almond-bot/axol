Every setting for `axol teleop`. Add any flag below to the command, or set it once in the control panel — see [Command configuration](/cli/configuration) for config files and syntax details.

```bash
axol teleop --axol.left_stiffness 0.8 --teleop.position_multiplier 1.5
```

## General

| Flag | Default | Description |
|---|---|---|
| `--sim` | `false` | Drive the browser visualiser instead of the robot. Robot gains and CAN channels are ignored. |
| `--mantis` | `false` | Drive the Mantis rigs' grippers from their triggers instead of the robot. |
| `--jelly_only` | `false` | Drive only Jelly; the arms are never touched. |
| `--left_channel` | `can_alm_axol_l` | CAN interface for the left arm. `null` disables the arm. |
| `--right_channel` | `can_alm_axol_r` | CAN interface for the right arm. `null` disables the arm. |
| `--cameras` | `{}` | Cameras to stream to the headset, as slot → serial: `"{overhead: 41234567, left_arm: 41234568}"`. Empty means no video. |
| `--camera_eyes` | `{}` | Which eye(s) of each stereo camera to stream: `"{overhead: both, left_arm: left}"`. Default is overhead both, wrists left. |
| `--resolution` | `null` | Capture resolution for all cameras: `SVGA`, `HD1080`, or `HD1200`. `null` keeps the camera default. |
| `--log_level` | `INFO` | `DEBUG`, `INFO`, `WARNING`, or `ERROR`. |
| `--config_path` | — | Load a JSON/YAML config file. Flags override it. |
