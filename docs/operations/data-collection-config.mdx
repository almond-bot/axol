Every setting for `axol collect-data`. Add any flag below to the command, or set it once in the control panel. See [Command configuration](/cli/configuration) for config files and syntax.

The [shared settings file](/guides/control-panel-settings) (`~/.almond/settings.json`) is read by default. It stores these flags in the sections below, without this command's prefixes.

| Flag | Section in the settings file |
|---|---|
| `robot_config.axol_config.*` | `axol` |
| `robot_config.left_channel`, `robot_config.right_channel` | `robot` |
| Other `robot_config.*` fields | `lerobot` |
| `teleop_config.vr_teleop_config.*` | `teleop` |
| `teleop_config.kinematics_config.*` | `kinematics` |
| `teleop_config.vr_server_config.*` | `vr_server` |
| `teleop_config.jelly.*` | `jelly` |
| `fps`, `root`, `vcodec`, `push_to_hub`, `rerun_*` | `recording` |

```bash
axol collect-data --repo_id myorg/pick --task "pick up the cup" \
  --robot_config.axol_config.left_stiffness 0.8 \
  --teleop_config.vr_teleop_config.position_multiplier 1.5
```

<Warning>
  Use the **same** stiffness, gripper torque, `observe_torques`, `observe_cartesian`, `fps` and cameras here and in [Run Policy](/operations/run-policy-config). A policy only works with the settings it was trained on.
</Warning>

## Recording

| Flag | Default | Description |
|---|---|---|
| `--repo_id` | required | Dataset ID, `<user>/<dataset>`. |
| `--task` | required | Task description stored with every frame. |
| `--fps` | `30` | Recording rate. Cameras capture at 60 and drop frames to match. `60` doubles the recording load on a Jetson. |
| `--teleop_hz` | `120` | Motor command rate (Hz) while teleoperating, independent of `fps`. |
| `--dataset_resolution` | `SVGA` | Resolution of the recorded video: `SVGA`, `HD1080` or `HD1200`. The headset stream keeps the capture resolution. |
| `--vcodec` | per platform | Dataset video codec: `h264` on Jetson, `auto` elsewhere. |
| `--root` | `null` | Local dataset directory. Default is the LeRobot cache, `~/.cache/huggingface/lerobot`. |
| `--push_to_hub` | `false` | Upload the dataset to the HuggingFace Hub when done. Log in first. See [Upload to the HuggingFace Hub](/operations/data-collection#upload-to-the-huggingface-hub). |
| `--qa_gate` | `true` | Don't save Mantis episodes that fail the quality check. `false` saves them anyway, except takes with a tracking fault under the [strict Lighthouse policy](/cli/tracker#lighthouse-tracking-policy). |
| `--rerun_ip` | `null` (off) | Stream live visualisation to a [Rerun](https://rerun.io) viewer at this address. |
| `--rerun_port` | `9876` | Rerun viewer port. |
| `--log_level` | `INFO` | `DEBUG`, `INFO`, `WARNING`, or `ERROR`. |
| `--config_path` | none | Load a JSON or YAML config file. Flags override it. |
| `--settings_path` / `--no_settings` | `~/.almond/settings.json` | Read another [shared settings file](/cli/configuration#the-shared-settings-file), or ignore it. The config file and flags override it. |

## Mantis

Only used with `--mantis`.

| Flag | Default | Description |
|---|---|---|
| `--mantis` | `false` | Record with the Mantis rigs instead of the robot: tracked gripper poses plus head and wrist cameras. |
| `--mantis_source` | `lighthouse` | Pose source: `quest`, `lighthouse` or `ultimate`. Defaults to the source chosen in **Mantis settings → Tracking**. |
| `--mantis_allow_uncalibrated` | `false` | Record without a tracker-to-gripper calibration. For bring-up only. Don't train on the result. |
| `--mantis_smooth_hz` | `10.0` | Smooths the recorded poses when the take is saved (cutoff in Hz). `0` turns it off. |

## Teleoperator {#teleop-config}

| Flag | Default | Description |
|---|---|---|
| `--teleop_config.has_gripper` | `true` | Set automatically from `--robot_config.axol_config.has_gripper`. |
| `--teleop_config.vr_teleop_config.gripper` | `parallel` | Set automatically from `--robot_config.axol_config.gripper`. Box mode is available only with `parcel`. |
| `--teleop_config.id` | `null` | Used by LeRobot only. Axol ignores it. |
| `--teleop_config.calibration_dir` | `null` | Used by LeRobot only. Axol ignores it. |
