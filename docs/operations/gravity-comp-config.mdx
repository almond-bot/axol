Every setting for `axol gravity-comp`. Add any flag below to the command, or set it once in the control panel. See [Command configuration](/cli/configuration) for config files and syntax.

The [shared settings file](/guides/control-panel-settings) (`~/.almond/settings.json`) is read by default. In it, the `axol` section holds the robot settings below. `--left_channel` and `--right_channel` live under `robot`, and `--kd` and `--rate_hz` under `gravity`.

```bash
axol gravity-comp --kd 0.8 --axol.left.elbow.mass 0.3
```

## General

| Flag | Default | Description |
|---|---|---|
| `--left_channel` | `can_alm_axol_l` | CAN interface for the left arm. `null` disables the arm. |
| `--right_channel` | `can_alm_axol_r` | CAN interface for the right arm. `null` disables the arm. |
| `--free_joints` | `null` (all) | Joints to free, such as `[WRIST_3]` or `[SHOULDER_1,ELBOW]`. The other joints hold their pose. `null` frees all seven. |
| `--kd` | `0.5` | Damping (Nm·s/rad) on freed joints. Higher is less floppy. |
| `--record` | `null` | Record the hand-guided motion to `~/.almond/recordings/<name>_*.npz` so [`motion.build`](/cli/motion-build) can turn it into a reference motion. |
| `--rate_hz` | `250.0` | Control-loop rate (Hz). |
| `--log_level` | `INFO` | `DEBUG`, `INFO`, `WARNING`, or `ERROR`. |
| `--config_path` | none | Load a JSON or YAML config file. Flags override it. |
| `--settings_path` / `--no_settings` | `~/.almond/settings.json` | Read another [shared settings file](/cli/configuration#the-shared-settings-file), or ignore it. The config file and flags override it. |

## Robot {#robot}

Arm stiffness, gripper limits and per-joint gains. Gravity compensation uses the `mass` and `com` values to hold the arm weightless. Adjust them if an arm sags or pushes back.
