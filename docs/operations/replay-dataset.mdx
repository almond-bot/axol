---
title: "Replay Dataset"
description: "Play a recorded LeRobot dataset episode back on Axol's arms."
---

Replay plays one episode of a recorded [LeRobot](/api/lerobot) dataset back on the arms. Axol moves to the rest pose, sends the episode's recorded actions to the motors frame by frame, then returns to rest. Episodes are recorded from rest, so playback starts without a jump. Start it from the web control panel or with `axol replay-dataset`.

Replay drives only the arms. It uses no headset, cameras or policy server.

<Warning>
  Replay doesn't watch the scene. It plays the recorded actions as they are.

  - Clear the workspace and set it up like it was when you recorded the episode.
  - Keep **Stop** or `Ctrl+C` within reach.
  - Use the same arm stiffness you recorded with, so the arms follow the actions the same way.
</Warning>

## Before you start

- Install Axol with the [one-command install](/installation). Bring up CAN and check the motors.
- Have a recorded dataset that you made or got from a source you trust. Dataset loading is not sandboxed. The dataset can be:
  - a local dataset under `--root` (`$HF_LEROBOT_HOME` by default),
  - a path to a dataset folder anywhere on disk, or
  - a dataset on the HuggingFace Hub, by its repo ID.

See [Data Collection](/operations/data-collection) to record one.

<Warning>
  Datasets recorded with these versions need converting once before you replay them:

  - Cartesian datasets recorded with axol 0.1.31 or earlier replay about 90° off. Run [`axol migrate-dataset`](/cli/migrate-dataset). Joint-space datasets don't need this.
  - **Mantis** datasets recorded with axol 0.2.4 or earlier barely move the arms. Run [`axol migrate-dataset --mantis-tcp-rotation`](/cli/migrate-dataset#mantis-tracker-gripper-rotation).
</Warning>

## Run it

<Tabs>
  <Tab title="Control Panel">
    <Steps>
      <Step title="Connect the robot">
        Connect the **Host Computer** and **Axol**. No cameras are needed.
      </Step>

      <Step title="Select Replay dataset and fill in the fields">
        Pick **Replay dataset** and fill in:

        - **Repo ID**: pick a dataset found on the host from the list, which shows each one's episode count. You can also type a repo ID or a folder path.
        - **Episode**: the episode number, counting from 0.
        - **Loop**: repeat the episode until you press **Stop**.
        - **Interpolate** (optional): smooth playback by filling in commands at about 120 Hz. Timing stays the same.

        Playback rate and stiffness are in the [Settings](/guides/control-panel#settings) tabs.
      </Step>

      <Step title="Start">
        Clear the workspace, then press **Start**. The arms move to rest, play the episode at its recorded speed, and return to rest. With **Loop** on, they return to rest between takes and repeat until you press **Stop**.
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    On the Host Computer:

    ```bash
    axol replay-dataset --repo_id myorg/pick-place --episode 0
    axol replay-dataset --repo_id myorg/pick-place --episode 0 --loop true   # loop until Ctrl+C
    ```

    Press `Ctrl+C` to stop. The arms return to rest before the command exits.

    - `--fps 0`, the default, plays at the dataset's recorded rate. Set a positive value to change it.
    - Set the stiffness you recorded with using `--robot_config.axol_config.left_stiffness` and `right_stiffness`.
    - `--repo_id` also takes a path to a dataset folder. If it can't find the dataset, it lists the ones it can find.

    See [`replay-dataset`](/cli/replay-dataset) for every field and [Command configuration](/cli/configuration) for the flag syntax.
  </Tab>
</Tabs>

## Contact stops

Every return to rest is guarded. If an arm meets resistance, the move stops and the arms go limp.

You can also stop playback when a joint pushes hard against something. This check is off by default. Set **Teleop contact stop** in **Axol settings → Robot** (`--teleop_torque_threshold` on the CLI). The panel suggests `16` Nm.

When it trips, playback stops and the arms go limp until you stop the run. Replay can't resume after a contact stop.
