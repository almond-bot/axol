The Axol software runs the Almond Axol dual-arm robot. You can run every operation in two ways:

- From the **web control panel** in a browser.
- From the **`axol` command line** in a terminal.

Each operation page below shows both.

<Note>
  **New here?** Start with [Hardware Setup](/hardware-setup) to mount and power Axol. Then [install the software](/installation) with one command, and go to [Teleoperation](/operations/teleop) to drive the robot from a VR headset.
</Note>
