Setting up Axol takes three steps:

1. **Mount and power Axol.** Pick the guide for your mount below.
2. **Fit the cameras.** If you have the Camera Kit, follow [Axol Cameras](/hardware-setup/cameras). It is the same for every mount.
3. **Install the software.** Follow [Installation](/installation).

<CardGroup cols={2}>
  <Card title="Axol Standalone" icon="table" href="/hardware-setup/standalone">
    Bolt Axol to your own table or fixture.
  </Card>
  <Card title="Axol + Owl Mount" icon="tower-cell" href="/hardware-setup/owl-mount">
    Bolt the column to a table or bench, then mount Axol.
  </Card>
  <Card title="Axol + Ox Cart" icon="cart-flatbed" href="/hardware-setup/ox-cart">
    Level the cart, set the crank height, and mount Axol.
  </Card>
  <Card title="Axol + Jelly" icon="robot" href="/hardware-setup/jelly">
    Charge, wire, and home the powered base, then mount Axol.
  </Card>
</CardGroup>

<CardGroup cols={2}>
  <Card title="Axol Cameras" icon="camera" href="/hardware-setup/cameras">
    Mount the Camera Kit's wrist and head cameras and wire them to the compute.
  </Card>
  <Card title="Advantech Thor (MIC-742)" icon="microchip" href="/hardware-setup/thor">
    Wire the cameras, install the operating system and add the camera driver on the Jetson Thor Compute Kit.
  </Card>
</CardGroup>

<Note>
  After you install the software, calibrate Axol so its arms move smoothly at slow speed. Follow [Calibrating Axol](/guides/axol-calibration). It takes one command and about 1.5 hours.
</Note>

Not sure which mount you have? See the [Hardware Overview](/hardware).
