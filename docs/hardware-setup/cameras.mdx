### Tools required

You need these hex (Allen) keys for the screws on the camera mounts:

| Screw | Hex key |
|---|---|
| M4 | 3&nbsp;mm |
| M3 | 2.5&nbsp;mm |
| M2 | 1.5&nbsp;mm |
