The Owl Mount is a rigid **400mm 8080 aluminum T-slot column**. Its base brackets fit **2020, 4040 and 4545** extrusion patterns. It ships with the Axol mounting plate and all the bolts you need to fix it to your table. For dimensions, see the [mount drawing](https://downloads.almond.bot/resources/static_mount.pdf).

### Tools required

You need a hex (Allen) key for the bolts:

| Screw | Hex key |
|---|---|
| M8 | 6&nbsp;mm |

### Fixing the column

<Steps>
  <Step title="Position the base brackets">
    Set the column where Axol will work, with its base brackets over the table's T-slots or your fixture's holes. Turn the column so its slots face where you want to run cables.
  </Step>
  <Step title="Bolt the brackets down">
    Drop T-nuts into the table slots. Pass the supplied bolts through the bracket holes that match your extrusion pattern, then tighten them with the 6&nbsp;mm hex key.
  </Step>
  <Step title="Check the column is plumb">
    Check that the column stands straight up from the table before you mount Axol. If the column leans, Axol is tilted in every task.
  </Step>
</Steps>
