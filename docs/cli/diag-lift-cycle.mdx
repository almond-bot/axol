---
title: "diag.lift-cycle"
description: "Raise the arms for clearance, then cycle Jelly's telescoping lift down and up."
---

Tests Jelly's telescoping lift with Axol mounted. The command:

1. Enables the seven arm joints on each selected side and moves both `shoulder_1` joints to the 90° clearance pose.
2. Runs the number of full **down, then up** cycles you ask for, while the arms hold the clearance pose.
3. Checks that the lift is fully up and stopped.
4. Moves `shoulder_1` back to 0° while the other arm joints hold where they are, checks the arm pose and lift state, then disables the arm joints.

It doesn't return the whole arm to its rest pose. It never enables, calibrates, moves or disables the grippers. The arms run on the same controller as [`teleop`](/cli/teleop).

```bash
axol diag.lift-cycle --cycles 3
axol diag.lift-cycle --cycles 5 --lift-channel can0
axol diag.lift-cycle --cycles 2 --speed 300
axol diag.lift-cycle --cycles 1 --no-right --left-channel can0
```

| Flag | Description |
|---|---|
| `--cycles N` | Number of down-and-up cycles. In a terminal, leave it out and the command asks. |
| `--speed N` | Lift speed limit in encoder counts/s: `0` for full speed, or 250 to 65535. Lower values are rejected so each move finishes within the lift's 60-second safety timeout. |
| `--lift-channel IFACE` | Lift CAN interface. Default: the chest bus `can_alm_axol_c` if it exists, otherwise the wheel bus `can_alm_axol_b`, as set up by [`can.setup`](/cli/can-setup). |
| `--left-channel IFACE` / `--right-channel IFACE` | Arm CAN interfaces |
| `--no-left` / `--no-right` | Leave out one arm, when only one is installed or connected. At least one arm is required to reach the clearance pose. |

The wheel motors don't need power. The command opens only the selected arm buses and the lift's bus, and never moves the wheels.

<Note>
  The lift must be homed first. Run [`axol lift.home`](/cli/lift-home). Both commands find the lift's bus the same way.
</Note>

<Note>
  Install Jelly Legs firmware v0.8 or newer before cycling. Any failed check stops the sequence:

  - When the first move starts, the command stops if an older firmware is running.
  - While the lift moves, it checks that `shoulder_1` stays clear and the other arm joints hold.
  - During the final `shoulder_1` return, it checks that the lift is still homed, stopped and fully up.
</Note>

<Warning>
  Clear people and objects from the arms, lift columns and Jelly before you start. The command moves the arms and drives the lift through its full range.

  Press Ctrl-C, or **Stop** in the diagnostics dashboard, to stop the lift right away. If anything fails, the arms stay enabled at their last pose. Check the lift and arms before you move them again.
</Warning>

You can also run this from the control panel's [diagnostics dashboard](/guides/diagnostics-dashboard) under **Diagnostics → Lift cycle**, where the number of cycles is a required field.
