---
title: "diag.rom-enable"
description: "Run a two-hour range-of-motion soak test that sweeps every joint."
---

Enables the motors, moves to home, then sweeps every joint through its range of motion for two hours. `wrist_2` and `wrist_3` stop 5° short of each limit, so their motors are never driven into the ends of travel. Every other joint sweeps to its full limit.

On a full-robot run, the command first asks you to clamp each gripper onto an item, and the grippers hold it for the whole test. When the test finishes, or when you press Ctrl-C, the robot returns home with the item still gripped and the motors still enabled. Run [`diag.rom-disable`](/cli/diag-rom-disable) afterwards to release the item and power down.

The arms run on the same controller as [`teleop`](/cli/teleop), so the test exercises the controller Axol ships with. Joint positions and torques are saved to a CSV under `~/.almond/diagnostics/captures` five times a second. You can chart the run in the [diagnostics dashboard](/guides/diagnostics-dashboard)'s run history.

With `--target mantis`, the test cycles only the two Mantis grippers, ID 8 on `can_mantis_l` and `can_mantis_r`. The arm-joint and grip steps don't apply.

```bash
axol diag.rom-enable
axol diag.rom-enable --no-right                          # left arm only
axol diag.rom-enable --joints wrist_1,wrist_2,wrist_3    # sweep only these joints
axol diag.rom-enable --web-prompts                       # dashboard-driven prompts
axol diag.rom-enable --no-capture                        # skip the telemetry CSV
axol diag.rom-enable --payload-kg 3                      # each gripper holds a 3 kg item
axol diag.rom-enable --no-right --left-channel can0      # one arm on a non-hub CAN adapter
axol diag.rom-enable --target mantis                     # both Mantis grippers
```

| Flag | Description |
|---|---|
| `--joints LIST` | Comma-separated joints to sweep. Every other joint holds home. |
| `--payload-kg KG` | Mass of the item each gripper holds (default: 2). See below. |
| `--target axol\|mantis` | What to test (default: `axol`) |
| `--no-left` / `--no-right` | Leave out one arm |
| `--left-channel IFACE` / `--right-channel IFACE` | CAN interface for each side (default: set by `--target`). With a single-channel adapter, combine an override with `--no-left` or `--no-right`. |
| `--web-prompts` | Show each hands-on gripper step as a **Continue** button in the dashboard instead of a terminal prompt. The dashboard sets this for you. |
| `--no-capture` | Don't save the telemetry CSV |

## Testing part of an arm

With `--joints`, the command first checks which motors answer on each bus.

- Every selected joint must answer, or the run fails and names the missing joint.
- A joint you didn't select that doesn't answer is treated as absent and left out. This lets a partly built arm on the bench run, for example `--joints wrist_2,wrist_3,gripper`.
- Every motor that answers is enabled and held, and the skipped joints are printed at the start. Make sure they really aren't attached, because an unpowered motor looks the same as a missing one.

A full-robot run still needs every motor. A run with `--joints` skips the grip step. If the gripper is selected, it opens and closes with nothing in it.

When arm joints are missing, the arm isn't on the robot, so the command drives it with soft gains and turns off gravity, friction, inertia and host damping. These are all set up for a full arm mounted on the robot, and the normal gains vibrate on a wrist clamped to a bench. The command prints `Partial arm — bench gains` when this applies. A fully built arm with only some joints selected keeps the normal gains, and so does a mounted arm whose gripper doesn't answer.

## Payload

On a full-robot run, `--payload-kg` is the mass of the item each gripper holds. It is added to the gravity model as each gripper closes, so the arms carry the item without sagging.

An item heavier than the setting makes the shoulders sag and buzz when the arm is held out. Set it to the item's real mass, or `0` for none. The dashboard shows it as **Payload kg per gripper**. Runs with `--joints` hold no item and ignore it.
