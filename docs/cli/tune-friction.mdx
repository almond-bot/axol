---
title: "tune.friction"
description: "Identify the friction-model parameters for one joint via a velocity sweep."
---

Identifies the four friction-model parameters for one joint via a bidirectional velocity sweep. Gravity is computed centrally from the URDF (see [Gravity compensation](/cli/gravity-comp)), so this command only fits the friction half-difference and a constant offset. Also available from the diagnostics dashboard (`axol serve`).

**Friction model:** `τ = Fc·tanh(0.1·k·v) + Fv·v + Fo`

Sweep safety is built in: shoulder_2 and wrist_2 sweep only their outboard side (shoulder_2 stays 10° out from 0 — the base and the chest cameras sit inboard of that), wrist_2 gets the elbow raised for gripper clearance, and shoulder_3 / wrist_1 sweeps hold shoulder_2 10° outboard so the hanging arm swings clear of the chest cameras.

Friction is motor-specific — the shared defaults in `config.py` were measured on one reference robot. Run this per joint, per arm, on every robot you build, and pass `--save` to persist the fit to that machine's calibration file (`~/.almond/calibration.json`). `AxolConfig` loads the file on construction, so saved values apply to every operation on the robot without a code change; explicit config overrides still win over them.

| Flag | Description |
|---|---|
| `--l` / `--r` | Arm side (required) |
| `--channel IFACE` | SocketCAN interface override for setups without the Axol hub adapter |
| `--joint JOINT` | `shoulder_1`, `shoulder_2`, `shoulder_3`, `elbow`, `wrist_1`, `wrist_2`, `wrist_3` (required) |
| `--kp FLOAT` | Proportional gain (default: from `AxolConfig`) |
| `--kd FLOAT` | Derivative gain (default: from `AxolConfig`) |
| `--velocities V [V ...]` | Velocity setpoints in deg/s (default: 7.2, 18, 36, 54, 72) |
| `--lo DEG` | Override lower joint limit for the sweep (degrees) |
| `--hi DEG` | Override upper joint limit for the sweep (degrees) |
| `--save` | Save the fitted parameters to `~/.almond/calibration.json` |
| `--dump-csv [PATH]` | Write per-bin `(v, q, tau_fwd, tau_bwd, tau_avg, tau_halfdiff)` rows to a CSV for offline plotting / arm-vs-arm comparison. Pass without a value to auto-name as `logs/friction_<side>_<joint>_<timestamp>.csv` |

```bash
axol tune.friction --l --joint shoulder_1 --kp 30 --kd 0.8
axol tune.friction --r --joint elbow --kp 20 --kd 0.6 --save
axol tune.friction --l --joint wrist_1 --velocities 12 35 60
axol tune.friction --l --joint shoulder_2 --dump-csv
```
