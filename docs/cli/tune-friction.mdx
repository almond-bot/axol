---
title: "tune.friction"
description: "Measure one joint's friction with a velocity sweep and save it to the robot's calibration."
---

Measures one joint's friction by sweeping it back and forth at several speeds. Gravity comes from the robot model (see [Gravity compensation](/cli/gravity-comp)), so this command fits only friction and a constant offset. You can also run it from the diagnostics dashboard (`axol serve`). To calibrate every joint at once, use [`tune.factory`](/cli/tune-factory).

**Friction model:** `τ = Fc·tanh(0.1·k·v) + Fv·v + Fo`

Friction differs from motor to motor, and the built-in defaults are only a starting point. Pass `--save` to store the fit in this computer's calibration file, `~/.almond/calibration.json`. Every operation on the robot then uses it. Values you set explicitly in the config still take priority.

## Profiles

| Profile | Speeds | What it fits |
|---|---|---|
| `standard` (default) | 7.2 to 72°/s | Sliding and viscous friction. |
| `slow` | 1 to 30°/s | The full model teleop uses for slow, smooth motion, including load and very-low-speed friction. Takes 5 to 8 minutes per joint. |

The slow profile sweeps the speeds under 8°/s twice: once where the joint carries the least load, and once where it carries the most. With `--save` it stores the friction fit and the `stribeck_*` fields.

On `shoulder_1`, `shoulder_2` and `elbow`, a saved slow-profile fit also switches the joint to stiffer [slow-motion gains](/operations/teleop-config). A joint without one keeps the standard gains. The `standard` profile doesn't switch them.

## Sweep safety

The tool poses the other joints so the arm stays clear of the robot:

- `shoulder_2` sweeps only outboard of rest, because inboard travel swings into the base.
- `wrist_2` sweeps with the elbow raised to its midpoint, which keeps the gripper clear of the base over its full range.
- `shoulder_3` and `wrist_1` sweep with `shoulder_2` held 10° outboard, clear of the chest cameras.

[`tune.gravity`](/cli/tune-gravity) uses the same poses, plus extra poses that load the test joint with gravity. The friction fit doesn't depend on the pose, so it works in either.

| Flag | Description |
|---|---|
| `--l` / `--r` | Arm side (required) |
| `--channel IFACE` | SocketCAN interface override for setups without the Axol hub adapter |
| `--joint JOINT` | `shoulder_1`, `shoulder_2`, `shoulder_3`, `elbow`, `wrist_1`, `wrist_2`, `wrist_3` (required) |
| `--kp FLOAT` | Proportional gain (default: the calibration gains below) |
| `--kd FLOAT` | Derivative gain (default: the calibration gains below) |
| `--profile {standard,slow}` | Sweep profile (default: `standard`) |
| `--velocities V [V ...]` | Sweep speeds in deg/s (default: `7.2 18 36 54 72`, or `1 2 3 5 8 15 30` with `--profile slow`) |
| `--stribeck-gain G` | With `--profile slow`: the share of the extra low-speed friction to cancel (default: 0.8 on `shoulder_1`, `shoulder_2` and `elbow`, 0 elsewhere) |
| `--raw-csv PATH` | Save every sweep sample, so you can refit later with `--fit-csv` |
| `--fit-csv PATH [PATH ...]` | Fit the slow-profile model to saved `--raw-csv` files without moving anything. `--save` still applies. |
| `--bins N` | Number of position bins the fit uses (default: 40) |
| `--lo DEG` | Override the lower sweep limit (degrees) |
| `--hi DEG` | Override the upper sweep limit (degrees) |
| `--save` | Save the fit to `~/.almond/calibration.json` |
| `--dump-csv [PATH]` | Write the binned sweep data to a CSV for plotting. Without a path it is named `logs/friction_<side>_<joint>_<timestamp>.csv`. |

## Calibration gains

The calibration tools (`tune.factory`, `tune.friction`, `tune.gravity`, `tune.breakaway`) move the arm under impedance control at these fixed gains, with gravity fed forward. They never use the motors' firmware position loops or the production gains. Every joint is held before anything moves.

| Joint | kp | kd |
|---|---|---|
| `shoulder_1`, `shoulder_2` | 250 | 3.5 |
| `shoulder_3` | 180 | 5 |
| `elbow` | 130 | 5 |
| `wrist_1` | 180 | 1.7 |
| `wrist_2` | 130 | 2.25 |
| `wrist_3` | 130 | 2 |

```bash
axol tune.friction --l --joint shoulder_1 --kp 30 --kd 0.8
axol tune.friction --r --joint elbow --kp 20 --kd 0.6 --save
axol tune.friction --l --joint wrist_1 --velocities 12 35 60
axol tune.friction --l --joint shoulder_2 --dump-csv
axol tune.friction --r --joint shoulder_1 --profile slow --raw-csv s1-slow.csv --save
axol tune.friction --r --joint shoulder_1 --fit-csv s1-slow.csv creep-s1.csv
```
