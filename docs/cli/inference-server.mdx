---
title: "inference-server"
description: "Serve policy inference on a separate, more powerful machine for run-policy."
---

Runs LeRobot's async-inference policy server, so [`run-policy`](/cli/run-policy) can run inference on a more powerful machine on the robot's network, such as a desktop with a GPU. The robot sends joint positions and camera frames to it over gRPC and gets actions back.

`run-policy` chooses the policy (`--policy_path`, `--policy_type` and `--device`), not the server. One server can serve different policies across sessions without a restart. The server loads the policy, so the path must be reachable from the server, such as a HuggingFace Hub repo ID or a local path on the server machine.

<Warning>
  Use this server only on a trusted network. The connection has no encryption or authentication:

  - Any client that can reach the port can make the server download and load a policy.
  - Another machine on the network can pose as the server and send the robot any actions.

  Put the inference machine and the robot on an isolated network or a VPN. Firewall the port so only the robot can connect, and never expose it on shared Wi-Fi or the internet. Load only policy checkpoints you trust.
</Warning>

```bash
axol inference-server                              # listen on 0.0.0.0:8765
axol inference-server --host 192.168.1.99          # explicit LAN interface
axol inference-server --host 192.168.1.99 --port 9000
```

Then, on the robot:

```bash
axol run-policy --server_host <server-ip> --policy_path myorg/pick-place-policy \
    --policy_type act --task "Pick the red cube" ...
```

| Flag | Description |
|---|---|
| `--host HOST` | Interface to listen on. Default `0.0.0.0`, the whole network. Use `127.0.0.1` for this machine only. |
| `--port INT` | gRPC port (default: 8765). Must match `run-policy`'s `--server_port`. |
| `--fps INT` | Action rate (default: 30). Must match `run-policy`'s `--fps`. |
| `--log_level {DEBUG,INFO,WARNING,ERROR}` | Default: `INFO` |
| `--config_path PATH` | Load a whole-config JSON/YAML file. Flags override it. See [Command configuration](/cli/configuration). |

<Note>
  Requires the `lerobot` extra, and a CUDA build of PyTorch on the server for GPU inference. Without `--server_host`, `run-policy` starts a policy server on the robot. You need this command only when inference runs on another machine.
</Note>
