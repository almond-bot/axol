---
title: "lift.home"
description: "Calibrate (home) Jelly's telescoping lift once, before you move it."
---

Calibrates Jelly's telescoping lift. The legs drive up to the top stop, then down to the bottom stop. When homing succeeds, the lift board sets the bottom as zero, sets soft limits a little inside the stops, and saves them. [`lift.goto`](/cli/lift-goto) and the teleop height display use this calibration.

```bash
axol lift.home                  # legs together (default, legs on the robot)
axol lift.home --independent    # each leg to its own stops (loose legs only)
```

There are two modes:

- **Together** (default): for legs bolted to the base, with or without Axol on top. The legs move as one, and when the first leg reaches a stop, both stop, so the frame is never twisted. Any height difference the legs start with is kept.
- **Independent** (`--independent`, or the **Independent** toggle in the dashboard dialog): for loose legs, for example before mounting or after you replace a leg. Each leg runs to its own stops and is zeroed at its own bottom, so legs that start at different heights end up level.

<Warning>
  Never home independently with the legs mounted. After the first leg reaches its stop, the other keeps pushing against the frame until its stall protection cuts it off.
</Warning>

Lift firmware older than v0.9 ignores the mode and always homes each leg independently.

Homing takes 1 to 2 minutes and touches both end stops on purpose. Progress prints as it runs. Press Ctrl-C, or **Stop** in the control panel, to stop safely. An interrupted homing goes back to the previous calibration, so the lift is never left half-homed.

<Info>
  You normally home the lift only once, not on every boot. The legs can't move without power, so the saved position stays valid across power cycles. Home again only if the columns were turned by hand or the lift lost power during a move.
</Info>

<Note>
  The lift's CAN bus must be set up with [`can.setup`](/cli/can-setup), and the lift board must have power. The command uses the chest bus `can_alm_axol_c` if it exists, otherwise the wheel bus `can_alm_axol_b`. Pass `--channel` to use a different interface. You can also run this command from the control panel's [diagnostics dashboard](/guides/diagnostics-dashboard) under **Diagnostics → Home the lift**.
</Note>
