---
title: "zed.install"
description: "Install the pyzed Python package that matches the installed ZED SDK."
---

Installs the `pyzed` Python package that matches the installed ZED SDK version. `pyzed` isn't on PyPI, so this command downloads it from Stereolabs and installs it into the `axol` environment. The download is cached in `~/.almond/wheels/`.

```bash
axol zed.install
axol zed.install --force   # reinstall even when the matching version is present
```

| Flag | Description |
|---|---|
| `--force` | Reinstall pyzed even when the matching version is installed. Without it, the command does nothing when pyzed already matches the SDK. |

`zed.install` checks the downloaded package's name, version and contents before it installs it, and refuses one that doesn't match.

<Note>
  Install the **ZED SDK** at `/usr/local/zed` first. `zed.install` reads the SDK version to pick the right package. If the SDK is missing, it exits with an error that points to the [Stereolabs download page](https://www.stereolabs.com/developers/release). The [one-command install](/installation) runs `zed.install` whenever the SDK is present.
</Note>
