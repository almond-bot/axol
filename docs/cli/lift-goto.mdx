---
title: "lift.goto"
description: "Move Jelly's telescoping lift to a target height."
---

Moves Jelly's telescoping lift to a height, given as a percentage of its homed travel. The default, **75%**, is the install height: high enough to slide Axol onto its Jelly mount.

```bash
axol lift.goto                  # 75%, the install height
axol lift.goto --percent 30
axol lift.goto --percent 100 --speed 300
```

The lift slows down as it reaches the target and keeps both legs level. The command reports the final height when the move ends. Press Ctrl-C, or **Stop** in the control panel, to stop the move right away.

`--speed` limits the speed in encoder counts/s. Full speed is about 650.

<Note>
  The lift must be homed. Run [`lift.home`](/cli/lift-home) once first. The lift board keeps its calibration across power cycles. You can also run this command from the control panel's [diagnostics dashboard](/guides/diagnostics-dashboard) under **Diagnostics → Raise lift (install height)**.
</Note>
