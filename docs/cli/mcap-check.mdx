---
title: "mcap.check"
description: "Check MCAP episodes from Collect data for missing video, joints, transforms, calibration or metadata."
---

`axol mcap.check` reads MCAP episodes recorded with **Recording format** set to `mcap` and reports what each one contains. See [MCAP Recording](/operations/mcap).

```bash
axol mcap.check ~/.cache/huggingface/lerobot/myorg/pick/episode_000000.mcap
```

Pass several files to check them all. Each line starts with one of these:

| Status | Meaning |
|---|---|
| `PASS` | The part is there and looks right. |
| `WARN` | The part is optional or wasn't checked. For example, the base topics on a robot without Jelly. |
| `FAIL` | A required part is missing or wrong. |

The command exits with status 1 if any line is `FAIL`.

It checks:

- each camera's video: H.265, a keyframe on every frame, increasing timestamps, no repeated frames, and the measured frame rate;
- `/joint_states` at 240 Hz with position, velocity and effort;
- the base topics on Axol on Jelly;
- a transform path from the root of the tree to each camera;
- the head stereo transform and the wrist camera mounts on `/tf_static`;
- the commands, end-effector targets and headset input;
- the episode, robot and calibration metadata;
- each camera's `camera_info`, its image size, and `equidistant` distortion for the wrist cameras.

The checker needs only the `mcap` and `mcap-ros2-support` Python packages. To run it on another computer, install them and run its source file, `almond_axol/recording/mcap/check.py`, with Python.
