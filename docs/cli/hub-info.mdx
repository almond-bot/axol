---
title: "hub.info"
description: "Show the firmware version and last reset of the Axol and Mantis hubs."
---

Prints each hub found on USB, both the Axol arm hub (the RP2350 USB-to-CAN bridge for both arms) and the Mantis hub (the same board and firmware): its USB serial and port, the firmware version it reports, and whether that is **current** or **outdated** against the firmware bundled with this package. Hubs are found on USB, not through their CAN interfaces, so a hub whose interfaces never came up is listed too. An RP2350 sitting in its bootloader is listed with the `hub.flash --port` command that recovers it.

```bash
axol hub.info
sudo axol hub.info
```

Run as root, it also reads the hub's last reset cause (power-on, brown-out, watchdog, …) and uptime — useful when an arm bus dropped out and you want to know whether the hub itself rebooted. That needs hub firmware 1.00 or newer; otherwise it prints `last reset unavailable`. The `USB` port path it prints (e.g. `1-3`) is what [`hub.flash --port`](/cli/hub-flash) takes.

It exits non-zero with `No Axol hub found on USB.` when no running hub is attached. A hub whose LED is on but that never shows up may have no working firmware: hold its BOOTSEL button while plugging it in, then run [`axol hub.flash`](/cli/hub-flash).
