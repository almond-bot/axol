---
title: "hub.info"
description: "Show the firmware version and last reset of the Axol Hub and Mantis Hub."
---

Lists every Axol Hub and Mantis Hub on USB. For each hub it prints:

- the USB serial number and port, such as `1-3`, which [`hub.flash --port`](/cli/hub-flash) takes
- the firmware version, and whether it is **current** or **outdated** compared with the firmware that ships with `axol`
- with `sudo`, the last reset cause (power-on, brown-out, watchdog) and the uptime

```bash
axol hub.info
sudo axol hub.info
```

The reset cause tells you whether the hub restarted when an arm bus dropped out. It needs hub firmware 1.00 or newer. On older firmware it prints `last reset unavailable`.

`hub.info` finds hubs on USB, so it also lists a hub whose CAN interfaces never came up. A hub in its bootloader is listed with the `hub.flash --port` command that recovers it.

If no running hub is attached, it prints `No Axol hub found on USB.` and exits with an error. If the hub's LED is on but it isn't listed, it may have no working firmware. Follow the manual flash steps in [`axol hub.flash`](/cli/hub-flash). They use the **BOOTSEL** switch next to the hub's USB port.
