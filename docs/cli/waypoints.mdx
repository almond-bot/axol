Teach poses by hand, then replay them. The arms hold in [gravity compensation](/cli/gravity-comp) so you can guide them. Each time you record, the pose of both arms is added to a waypoint file.

On playback each gripper tip moves in a straight line from waypoint to waypoint, and its orientation turns smoothly along the way. The [IK solver](/api/kinematics) turns each point on the line into joint angles. At each waypoint the arms pause to open or close the grippers.

- The straight line is held at the point where the fingers close, 145 mm past the gripper mount. The tip doesn't swing in an arc when the wrist turns.
- Each move starts and stops smoothly, with no jolt.
- The whole path is planned before the arms move. If a waypoint can't be reached in a straight line, you find out while the robot is still.
- An arm you didn't move holds still. An arm resting in gravity compensation drifts a millimetre or two between recordings. Below `--min_travel` and `--min_rotation`, playback keeps that arm in place instead of chasing the drift.

Arm stiffness is the same setting every operation uses: the control panel's setting, or `--axol.left_stiffness` and `--axol.right_stiffness`. A stiffer arm follows the path more closely. A softer one sags a little, but shakes less when bumped and gives way if the path meets an obstacle. Stiffness doesn't affect hand-guiding.

This command is configured through draccus (see [Command configuration](/cli/configuration)). Arm gains and stiffness are on the nested `axol` config, and IK weights are on `kinematics`. They are the same fields as teleop's [Robot](/operations/teleop-config#robot) and [Kinematics](/operations/teleop-config#kinematics) parameters, with the same `--axol.` and `--kinematics.` prefixes. The command's own flags are listed below.

## Driving a session

On the terminal, single keys on stdin:

| Key | Action |
|---|---|
| `Enter` | Record the pose both arms are in |
| `u` | Undo the last waypoint |
| `c` | Clear every waypoint |
| `[` / `]` | Open or close the left / right gripper |
| `p` | Play the path |
| `s` | Stop playback and go back to teaching |
| `q` | Quit |

The same actions are buttons in the [control panel](/guides/control-panel), so you can teach and replay a path without a terminal.

## Grasping

A gripper is either open or closed. Press `[` for the left gripper and `]` for the right, so one arm can carry something while you guide the other. Both start open. Each waypoint stores the state both grippers are in when you record it:

```text
[  ] guide above the object, record      -> both open
[  ] press ], guide down, record         -> right closed: the grasp
[  ] guide to the destination, record    -> right still closed: carrying
[  ] press ], record                     -> right open: let go
```

On playback the arms hold still while a gripper moves, so the grasp closes on the object at its waypoint rather than somewhere along the way. Waypoints that don't change a gripper don't pause for it.

Grip force is the gripper's `torque_limit`, the same setting every operation uses, and you can set it in the control panel. A closed waypoint always commands **fully closed**, not the point where the fingers stopped on the object, so the gripper keeps squeezing. Set the torque to suit the object.

<Tip>
  Before anything moves, planning logs what each waypoint asks the grippers to do. It warns you when a path never moves the grippers, which can look like a broken gripper.
</Tip>

## Flags

| Flag | Description |
|---|---|
| `--file PATH` | Waypoint file to record into and play back from. Written after every change. Default `~/.almond/waypoints.json` |
| `--play_only BOOL` | Skip teaching and replay the file straight away. Default `false` |
| `--sim BOOL` | Preview a saved path in the browser visualizer instead of on the robot (implies `--play_only`). Default `false` |
| `--loops INT` | Times to run the path; `0` replays until stopped. Default 1 |
| `--speed FLOAT` | Average gripper speed (m/s) along each move. The peak mid-move is 1.875 times this. Default 0.25 |
| `--ang_speed FLOAT` | Speed (rad/s) at which the gripper turns. Default 1.2 |
| `--speed_scale FLOAT` | Factor in `(0, 1]` that slows every move in the session, including the approach and the return to rest. Control panel: **Speed scale** slider. Default 1.0 |
| `--dwell FLOAT` | Seconds held still at each waypoint after its grippers have moved. Default 0.5 |
| `--grip_time FLOAT` | Seconds to open or close the grippers at a waypoint. Skipped when the grippers don't change. Default 0.75 |
| `--pos_tolerance FLOAT` | Largest allowed distance (m) from the straight line when planning. Default 0.01 |
| `--plan_rate_hz FLOAT` | Fewest IK solves per second of motion when planning. Fast moves can get more. Default 10 |
| `--min_travel FLOAT` | An arm whose gripper tip moves less than this (m) between two waypoints holds still for that move. Default 0.01 |
| `--min_rotation FLOAT` | Rotation counterpart to `--min_travel` (rad). Default 0.05 |
| `--ease_in FLOAT` | Seconds to blend onto the start of each move, so the arm joins the path smoothly. Default 0.4 |
| `--free_joints [J1,J2,...]` | Joints to gravity-compensate while teaching. Default `null` = all 7 |
| `--kd FLOAT` | Velocity damping on free joints while teaching (Nm·s/rad). Default 0.25 |
| `--left_channel <ch\|null>` / `--right_channel <ch\|null>` | CAN channel per arm; `null` disables that arm. |
| `--rate_hz FLOAT` | Control loop and waypoint rate in Hz (default: 250) |
| `--log_level {DEBUG,INFO,WARNING,ERROR}` | Default: `INFO` |
| `--config_path PATH` | Load a whole-config JSON/YAML file. Flags override it. |
| `--settings_path PATH` / `--no_settings` | Read another [shared settings file](/cli/configuration#the-shared-settings-file), or ignore it. By default `~/.almond/settings.json` applies, beneath `--config_path` and the flags. |

```bash
axol waypoints                                  # teach, then play
axol waypoints --file pick_place.json           # keep a named path
axol waypoints --play_only --loops 0            # replay it until stopped
axol waypoints --sim --file pick_place.json     # preview it in the browser
axol waypoints --speed 0.03 --dwell 2           # slow, with a long pause
axol waypoints --speed 0.5                      # brisk
axol waypoints --play_only --speed_scale 0.25   # first run of a new path at quarter pace
```

### Choosing a speed

At the default speed the gripper peaks at about 0.47 m/s mid-move. Lines stay straight at any speed. Acceleration grows with the square of the speed: about 2 m/s² at the default, 8 at `--speed 0.5` and 16 at `--speed 0.7`. Above that, each move takes a fraction of a second and the pause at each waypoint takes most of the cycle.

Lowering `--speed` alone doesn't slow a move that is mostly turning, because `--ang_speed` may set its pace. `--speed_scale` (the **Speed scale** slider in the control panel) slows both, and the moves to the first waypoint and back to rest. Use it to try a new path slowly.

<Warning>
  A fast move carries real momentum, and a stiff arm won't give way if the path meets something. Raise the speed step by step, with the workspace clear.
</Warning>

## The waypoint file

Waypoints are stored as the joint angles the arms reported, so a path is exact. You can edit the file or check it into a repository:

```json
{
  "version": 1,
  "waypoints": [
    {
      "label": "approach",
      "left": [-0.157, 0.0, 0.0, 0.314, 0.0, 0.0, -0.157, 1.0],
      "right": [0.157, 0.0, 0.0, -0.314, 0.0, 0.0, 0.157, 1.0]
    }
  ]
}
```

Each arm entry is 7 joint angles in radians (`SHOULDER_1` to `WRIST_3`, 0 = rest), then the gripper opening from `0` to `1`. The joint angles are what the arm reported. The gripper value is the opening to command, such as `0.0` for a grasp, not where the fingers stopped. The gripper poses for planning are computed from the joint angles.

<Tip>
  A 7-joint arm can reach the same gripper pose in several ways. Playback keeps the posture you taught, so the elbow follows the path you guided it along instead of swinging somewhere unexpected.
</Tip>

<Note>
  Playback starts with a collision-aware move to the first waypoint. When the path finishes or is stopped, the arms park at the rest pose. If you quit while teaching, the arms don't park, since your hands are on them.
</Note>
