---
title: "diag.rom-disable"
description: "Open the grippers left clamped by the range-of-motion test and power down."
---

Releases the items gripped by [`diag.rom-enable`](/cli/diag-rom-enable) and disables the robot. The command connects to the motors without recalibrating them, because a normal enable would open the grippers at once and drop the items. It opens one gripper at a time so you can catch each item, then disables all motors.

The arms don't move. They hold the pose the test left them in until the final disable.

After a Mantis gripper test, pass `--target mantis`. The command then addresses only ID 8 on each selected Mantis bus.

```bash
axol diag.rom-disable
axol diag.rom-disable --web-prompts   # dashboard-driven "Continue" before each gripper opens
axol diag.rom-disable --no-right --left-channel can0   # one arm on a non-hub CAN adapter
axol diag.rom-disable --target mantis                 # both Mantis grippers
```

| Flag | Description |
|---|---|
| `--target axol\|mantis` | Pass the same target the `diag.rom-enable` run used |
| `--no-left` / `--no-right` | Leave out one arm |
| `--left-channel IFACE` / `--right-channel IFACE` | CAN interface for each side (default: set by `--target`). Pass the same channels the `diag.rom-enable` run used. |
| `--web-prompts` | Show a **Continue** button in the dashboard before each gripper opens, instead of a terminal prompt. The dashboard sets this for you. |
