---
title: "motor.health"
description: "Check that every motor on both arms responds."
---

Checks all 16 Axol motors (8 per arm), or both Mantis grippers with `--target mantis`. For each motor it runs the same reads as [`motor.info`](https://docs.almond.bot/cli/motor-info), such as position, temperature, voltage and error code. It prints one line per joint, left arm first: `OK` if every read succeeds, or the error if one fails.

It exits with status `1` if any motor fails to respond, so you can use it in scripts.

| Flag | Description |
|---|---|
| `--target {axol,mantis}` | Check the Axol arms or the Mantis grippers (default: `axol`). Mantis checks only ID 8 on `can_mantis_l` and `can_mantis_r` |
| `--no-left` / `--no-right` | Skip one side |
| `--left-channel IFACE` / `--right-channel IFACE` | Use this SocketCAN interface for that side instead of the default |
| `--joints JOINTS` | Comma-separated subset of joints to check |

```bash
axol motor.health
axol motor.health --no-right --left-channel can0   # one arm on a non-hub CAN adapter
axol motor.health --target mantis                   # both Mantis grippers
```
