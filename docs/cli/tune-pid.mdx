---
title: "tune.pid"
description: "Compare and rank Kp/Kd gains for one joint with a sine or step test."
---

Tests one or more `Kp`/`Kd` pairs on a single joint. Pass several values to `--kp` or `--kd` to test every combination in one session. The tool measures tracking error (RMS, max, overshoot, settling time), ranks the candidates, and can save the best one to this robot's calibration file. You can also run it from the diagnostics dashboard (`axol serve`).

## Feed-forward

By default the test applies the same feed-forward as teleop: gravity, friction, inertia (`j_eff`) and host damping (`kd_host`). Gains you find here carry over to teleop unchanged.

- `--ff` tests with less feed-forward. For example, `--ff none` runs bare PD, and `--ff friction` shows the joint without gravity compensation.
- `--host-kd` overrides the host damping. The shoulders need host damping, because the motor's own `kd` alone leaves them ringing at about 2 Hz.

## Other joints

During each test the other joints hold their rest pose under impedance control, with gravity fed forward. The tool checks that they stayed put. Each candidate's report ends with a `Holder peak` line that shows how far each held joint moved. If a held joint moved more than about 0.5°, the arm was flexing, and part of the measured ringing comes from that joint and not the one under test.

| Flag | Description |
|---|---|
| `--l` / `--r` | Arm side (required) |
| `--channel IFACE` | SocketCAN interface override for setups without the Axol hub adapter |
| `--joint JOINT` | `shoulder_1`, `shoulder_2`, `shoulder_3`, `elbow`, `wrist_1`, `wrist_2`, `wrist_3` (required) |
| `--kp KP [KP ...]` | Proportional gain candidates (default: the joint's configured kp) |
| `--kd KD [KD ...]` | Derivative gain candidates (default: the joint's configured kd) |
| `--ff {full,gravity,friction,none}` | Feed-forward during the test (default: `full`, the same as teleop) |
| `--host-kd KD` | Host damping in Nm·s/rad, the same as the config's `kd_host` (default: the joint's configured value) |
| `--host-kd-hz HZ` | Center of the band the host damping acts in, the same as `kd_host_hz`. Set it to the ring frequency the step test reports (default: the joint's configured value, else 3.2 Hz). |
| `--host-kd-q Q` | Width of that band, the same as `kd_host_q`: bandwidth is the center divided by Q (default: the joint's configured value, else 0.8). See below. |
| `--stiffness S` | Test the production gains at this stiffness-slider position, 0 to 1. Can't be combined with `--save`. |
| `--mode {sine,step}` | `sine` tracks a sine wave (default). `step` measures a step response. |
| `--amp DEG` | Motion amplitude in degrees (default: 10°, limited to the room the joint has) |
| `--center DEG` | Center of the test, joint-frame degrees with 0 at rest (default: a step starts where the joint is, a sine centers on its midpoint). See below. |
| `--pose JOINT=DEG` | Hold another joint at this joint-frame angle during the test. Repeatable, see below. |
| `--pose-by-hand` | Pose the arm by hand between tests. See below. |
| `--hold-host-kd KD` | With `--pose-by-hand`: cap the host damping on the held joints |
| `--a4-holders` | Hold the other joints on their firmware position loops instead of impedance. This is stiffer but can make a shoulder oscillate, so keep a hand on the E-Stop. |
| `--target-noise DEG` | Sine only: add about 8 Hz noise of this RMS to the target, like hand-tracking jitter. Try 0.1 to 0.3. |
| `--freq FLOAT` | Sine frequency in Hz (default: 1.0) |
| `--duration FLOAT` | Sine duration in seconds (default: 5.0) |
| `--hold FLOAT` | Step hold time per phase in seconds (default: 2.0). The joint also settles this long before the step. |
| `--rate FLOAT` | Command rate in Hz (default: 240, the teleop control rate). The report prints the rate it reached and warns if the CAN bus held it below the request. |
| `--save` | Save the best candidate's Kp/Kd to `~/.almond/calibration.json` |
| `--no-imu` | Skip the wrist IMU. By default each candidate gets an `imu` shake score (see [`tune.motion`](/cli/tune-motion)). |
| `--save-run` | Save each candidate's time series and scores under `~/.almond/diagnostics/tuning/` for the diagnostics dashboard |
| `--label TEXT` | Note stored on each saved run |
| `--dump-csv [PATH]` | Write every sample (`kp, kd, t, target, actual, error`) to a CSV for plotting. Without a path it is named `logs/pid_<side>_<joint>_<timestamp>.csv`. |

```bash
axol tune.pid --l --joint elbow                              # config gains, production FF
axol tune.pid --l --joint elbow --kp 20 30 45 --kd 0.5 1.0   # 6-way sweep, ranked
axol tune.pid --r --joint shoulder_1 --mode step --ff none   # bare-PD step response
axol tune.pid --l --joint wrist_1 --kp 12 --kd 0.4 --save    # persist to calibration
```

## Testing in the worst pose

Gains that are stable with the arm hanging at rest can ring under gravity load or with the arm extended. Test the worst case too.

- **`--center`**: run the test at other angles, such as 45 and −45. `shoulder_2` may start at 0 but must swing outboard, because the base is inboard. `wrist_2` runs with the elbow raised to its midpoint, which keeps the gripper clear of the base.
- **`--pose`**: hold other joints in a pose, for example `--pose elbow=90 --pose wrist_1=45`. In the dashboard, enter them in one field separated by spaces. Posed joints return to where they were after the test. `shoulder_2` may only be posed outboard. `wrist_2` may only be posed in its inboard half if the pose also bends the elbow at least 30°.
- **`--pose-by-hand`**: the arm floats in gravity compensation so you can move it by hand. Press Enter to hold the pose, and the tool runs a step test with every candidate. Compare the ring frequency across poses. The pose with the lowest ring frequency has the least damping margin. It needs `--mode step` and can't be combined with `--center`, `--pose` or `--save`.

## Host damping band

At the default Q of 0.8, the damping band reaches an octave either side of its center. With a low center, it reaches into the slow, intentional motion below 1.5 Hz, drags the final approach, and the step never settles. Once you know the ring frequency, set `--host-kd-hz` to it and use a Q of 2 to 3, so only the ringing is damped.

## Per-robot calibration

`--save` writes the best gains to `~/.almond/calibration.json`. Every operation on this computer (teleop, data collection, policies) then uses them in place of the built-in defaults.

Explicit overrides still take priority, such as `--axol.left.elbow.kp 60` or the panel's Advanced settings. Saved gains apply at full stiffness (stiffness slider at 1, the default), like the defaults they replace. Friction values from [`tune.friction --save`](/cli/tune-friction) live in the same file.
