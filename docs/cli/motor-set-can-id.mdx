---
title: "motor.set-can-id"
description: "Change a motor's CAN ID and persist it to flash."
---

Changes a motor's CAN ID and persists it to flash. The motor must be the only device on the bus or its current ID must be known. `--type` is required here.

| Flag | Description |
|---|---|
| `--l` / `--r` | Select the left or right side (mutually exclusive, required) |
| `--target {axol,mantis}` | Use that side's Axol arm or Mantis gripper bus (default: `axol`) |
| `--channel IFACE` | Override the selected hardware's default SocketCAN interface (e.g. `can0`) |
| `--current-id ID` | Current CAN ID (hex or decimal, required) |
| `--new-id ID` | New CAN ID to assign (hex or decimal, required) |
| `--type {myactuator,damiao}` | Motor type (required) |

```bash
axol motor.set-can-id --l --current-id 0x01 --new-id 0x03 --type myactuator
axol motor.set-can-id --target mantis --l --current-id 0x01 --new-id 0x08 --type damiao
```
