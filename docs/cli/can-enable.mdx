---
title: "can.enable"
description: "Bring the CAN interfaces up by hand."
---

Brings up the CAN interfaces that [`can.setup`](/cli/can-setup) configured. You rarely need it, because the interfaces come up on every boot and whenever an adapter is plugged back in. Use it after you take the interfaces down yourself, or if they didn't come back after a replug. Run [`can.setup`](/cli/can-setup) first.

```bash
axol can.enable                      # every configured Axol/Mantis interface
axol can.enable --channels can0      # one non-hub adapter
axol can.enable --channels can0 can1 # two adapters / channels
```

With no flags, `can.enable` brings up every interface `can.setup` configured: the arms, Mantis, and [Jelly](/guides/vr-interface#jelly)'s wheel and lift buses. It skips any adapter that is unplugged. [`axol teleop`](/cli/teleop) also brings up Jelly's interfaces when it starts.

## Adapters other than the Axol Hub

Pass `--channels` with one interface for a single arm, or two for both. `can.enable` sets each one to 1 Mbit/s and brings it up. Interfaces that are already up are left alone. This form doesn't need `can.setup`.
