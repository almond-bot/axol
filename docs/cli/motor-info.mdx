---
title: "motor.info"
description: "Print the status of one motor, or every motor on a bus."
---

Prints the status of one motor, or of every motor on the bus when you omit `--id`. Use it to check that a motor answers at a given CAN ID. It shows position, velocity, torque, temperature, voltage and the status or error code. MyActuator motors also report their model and firmware version, and Damiao motors report their control mode.

| Flag | Description |
|---|---|
| `--l` / `--r` | Select the left or right side (mutually exclusive, required) |
| `--target {axol,mantis}` | Use that side's Axol arm or Mantis gripper bus (default: `axol`) |
| `--channel IFACE` | Use this SocketCAN interface instead of the default, such as `can0` |
| `--id ID` | Motor CAN ID, hex or decimal. Omit to query IDs 1 to 8 on Axol, or ID 8 on Mantis |
| `--type {myactuator,damiao}` | Motor type. Inferred from the ID if omitted |

```bash
axol motor.info --l                   # scan all 8 motors on the left bus
axol motor.info --l --id 0x01
axol motor.info --r --id 6 --type damiao
axol motor.info --target mantis --l   # left Mantis gripper (ID 8)
```
