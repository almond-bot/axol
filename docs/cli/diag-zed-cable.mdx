---
title: "diag.zed-cable"
description: "Check a ZED camera cable by capturing and checking frames."
---

Checks a ZED camera's GMSL cable end to end. The command restarts the ZED X service, opens the camera and captures frames for 5 seconds. It checks that:

- each frame has the right resolution, real image detail and normal brightness
- frames keep arriving, without long pauses or repeated frames

It exits with an error on any failure. Dropped, garbled or frozen frames point at a bad cable.

Run it with exactly one ZED camera connected, either a ZED X One (mono) or a ZED X (stereo). The command detects which one. Pass `--kind mono` or `--kind stereo` to choose. It doesn't touch the arms, so you can run it while the diagnostics dashboard shows live motor data.

```bash
axol diag.zed-cable
axol diag.zed-cable --kind stereo                   # force the stereo (ZED X) pipeline
axol diag.zed-cable --output logs/cable_frame.png   # also save the last frame as PNG
```

You can also run it from the [diagnostics dashboard](/guides/diagnostics-dashboard).
