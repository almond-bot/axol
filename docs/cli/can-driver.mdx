---
title: "can.driver"
description: "Install a gs_usb kernel driver that works with the Axol Hub."
---

Builds and installs the `gs_usb` USB CAN kernel driver for the running kernel. You need it on NVIDIA Jetson and ZED Box computers, whose kernels ship without USB CAN drivers. Without it the Axol Hub shows up on USB, but no `can*` network interfaces appear.

```bash
axol can.driver
```

<Note>
  [`can.setup`](/cli/can-setup) runs this check for you, so you rarely need to run it yourself.
</Note>

## What it does

- If the kernel's own driver supports every adapter that is plugged in, it keeps that driver. Linux 6.13 and newer, and many maintained 6.2+ distribution kernels, fall in this group.
- Otherwise it builds Almond's driver from source and installs it under `/lib/modules/$(uname -r)/updates/`. The driver then loads on every boot.
- If the install or load fails, it restores the previous driver.

Almond's driver is the Linux 5.15 `gs_usb` driver with the fixes the Axol Hub needs: it tells the left and right arm channels apart, finds the hub's USB endpoints, and fixes receive-path crashes. See `almond_axol/cli/can/gs_usb/README.md` for the full list.

Building needs the kernel headers and `build-essential`. Both ship with JetPack.

## After a kernel update

The driver is built for the exact running kernel. Rebooting into the same kernel needs no action. After a JetPack or other kernel update changes `uname -r`, run `axol can.driver` or `axol can.setup` once under the new kernel to rebuild it.

## Secure Boot

On a computer that enforces module signatures, `can.driver` refuses to install an unsigned driver and leaves the current one in place. Sign the module with an enrolled key, or use a newer kernel whose built-in driver supports your adapters.
