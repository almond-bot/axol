---
title: "replay-dataset"
description: "Replay a recorded LeRobot dataset episode on the robot."
---

Replays one episode of a [LeRobot](https://github.com/huggingface/lerobot)-format dataset on Axol. The episode's recorded `action` column is sent to the arms frame by frame, then the robot returns to its rest pose. It's the reverse of [`collect-data`](/cli/collect-data): instead of recording actions, it plays recorded ones back on the hardware.

Replay drives only the arms. It uses no cameras, teleop or policy server.

1. The arms move to the rest pose along the same collision-aware path [`run-policy`](/cli/run-policy) uses. This first move goes through zero. Episodes are recorded from rest, so playback starts without a jump.
2. Each frame is sent at the dataset's recorded fps, so the motion keeps its original timing.
3. At the end the arms park: rest pose, then, with `--park_to_zero` (on by default), the all-zero pose, holding their grasp.

With `--interpolate true`, the recorded actions are spread over commands at about 120 Hz for smoother motion. The episode's timing doesn't change.

Replay refuses to start while any arm joint is more than 25° from zero, and names each joint that is out. See [Starting needs the arms near zero](/operations/teleop).

Pass `--loop true` to replay the episode over and over, returning to rest between takes, until you press `Ctrl+C` or **Stop** in the [control panel](/guides/control-panel). Either way, the arms return to rest before the command exits.

<Note>
  From the control panel, `--repo_id` must name a dataset under the configured dataset root. Passing a dataset folder path works only from the CLI.
</Note>

<Warning>
  Replay only datasets you created or obtained from a trusted source. Loading a
  dataset is not sandboxed.
</Warning>

This command is configured through draccus. The robot settings (CAN channels, per-joint gains) live in the nested `robot_config`. Set them with dotted flags or a whole-config file. See [Command configuration](/cli/configuration) for the syntax and [Replay Dataset Config Parameters](/operations/replay-dataset-config) for every field with its default.

| Flag | Description |
|---|---|
| `--repo_id <id-or-path>` | Dataset to replay (required). A repo ID under `--root` (e.g. `myorg/pick-place`), a HuggingFace Hub repo ID to download, or the path of a dataset folder (one containing `meta/info.json`). If it isn't found, the error lists the datasets on the machine. |
| `--episode INT` | Index of the episode to replay, starting at `0` (required) |
| `--fps INT` | Playback frame rate. `0` (default) uses the dataset's recorded fps. |
| `--interpolate true` | Interpolate between recorded actions and command the arms at about 120 Hz. Timing doesn't change. Default: off. |
| `--loop true` | Replay the episode until stopped with `Ctrl+C` or **Stop**, returning to rest between takes. Default: off. |
| `--reset_torque_threshold FLOAT` | Contact limit (Nm) for every return to rest (default: 6.0). `0` turns it off. |
| `--reset_gravity_comp_kd FLOAT` | Damping (Nm·s/rad) while the arms hang limp after a contact stop (default: 0.25). Same as [`gravity-comp`](/cli/gravity-comp) `--kd`. |
| `--teleop_torque_threshold FLOAT` | Contact limit (Nm) during playback (default: `0`, off). The control panel suggests `16.0`. |
| `--park_to_zero BOOL` | After the last take, and on **Stop** or `Ctrl+C`, move the arms from rest on to the all-zero pose before releasing the motors (default: `true`). Control panel: **Park to zero on stop**. |
| `--root PATH` | Local dataset root (default: `$HF_LEROBOT_HOME`) |
| `--robot_config.axol_config.left_stiffness S` | Left arm stiffness in `[0, 1]` (default: 1, the tuned production gains). Match the value used to record, so the arm tracks the actions the same way. Use `right_stiffness` for the right arm. See [`AxolConfig.left_stiffness`](/api/robot). |
| `--log_level {DEBUG,INFO,WARNING,ERROR}` | Default: `INFO` |
| `--config_path PATH` | Load a whole-config JSON/YAML file. Flags override it. |
| `--settings_path PATH` / `--no_settings` | Read another [shared settings file](/cli/configuration#the-shared-settings-file), or ignore it. By default `~/.almond/settings.json` applies, beneath `--config_path` and the flags. |

If a joint pushes hard against something during a return to rest, or during playback with `--teleop_torque_threshold` set, the arms stop and go limp in a gravity-compensation hold. Replay can't retry, so free the arms and stop the run with `Ctrl+C` or **Stop**.

```bash
axol replay-dataset --repo_id myorg/pick-place --episode 0
axol replay-dataset --repo_id myorg/pick-place --episode 0 --loop true   # loop until Ctrl+C
axol replay-dataset --repo_id myorg/pick-place --episode 3 --fps 30 \
    --robot_config.axol_config.left_stiffness 1.0 --robot_config.axol_config.right_stiffness 1.0
```

<Warning>
  Replay drives the arms from the recorded actions without watching the scene. Only the optional `--teleop_torque_threshold` stops it if a joint hits something. Before you start, clear the workspace and set it up roughly as it was when the episode was recorded. Keep the [Stop](/cli/serve) control or `Ctrl+C` within reach.
</Warning>
