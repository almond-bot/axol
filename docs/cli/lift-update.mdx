---
title: "lift.update"
description: "Update the lift board's firmware over CAN."
---

Installs new Jelly Legs firmware on the lift board over its CAN bus. You don't need a USB cable or to open the chest.

```bash
axol lift.update                                  # show the running firmware
axol lift.update --firmware build/firmware.bin    # install a build
axol lift.update --firmware firmware.bin --force  # reinstall the same build
```

Use the build's `firmware.bin` file, not the `.uf2` or `.elf`. The update takes about a minute:

1. The new firmware is copied to the board while the current firmware keeps running. The board accepts it only if the whole file arrived, its checksum matches, and it is Jelly Legs firmware. Anything else is rejected and nothing changes.
2. The board restarts into the new firmware on trial, with lift motion locked.
3. When the new firmware reports the expected build, the command confirms it and the update becomes permanent.

If the new firmware is never confirmed, the board goes back to the previous firmware within 15 s. This covers a crash, a hang, a power loss or a stopped command. The lift keeps its saved height and homing across the update.

- Press Ctrl-C, or **Stop** in the control panel, during the transfer to cancel it. Nothing is installed.
- If the board already runs that build, the command says so and does nothing. Pass `--force` to install it again.
- The lift must be idle. The command waits up to 10 s for a move or a pending position save to finish, and saving needs the 24 V supply on.

<Warning>
  The board must already run lift firmware 0.9 or newer, installed once over USB with its partition table. See the Jelly Legs firmware README in the circuits-py repo. Older firmware doesn't answer this command and must be updated over USB. Flashing the board over SWD erases the partition table, so it then needs the USB install again before it can update over CAN.
</Warning>

<Note>
  You can also update from the control panel's [diagnostics dashboard](/guides/diagnostics-dashboard) under **Diagnostics → Helpers → Update lift firmware**. Choose the `firmware.bin` on your computer, and the dialog uploads it and shows its version and build date. Then press **Run** to install it.

  The command uses the lift bus set up by [`can.setup`](/cli/can-setup). Pass `--channel` to use a different interface.
</Note>
