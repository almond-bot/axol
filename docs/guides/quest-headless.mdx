---
title: "Quest Without Wearing It"
description: "Turn off the Quest's proximity sensor so teleop and data collection keep running with the headset set down."
---

The Quest's proximity sensor, inside the visor between the lenses, puts the headset to sleep when nobody is wearing it. Sleep pauses the VR session, which stops the controller poses and the camera feeds. A headset set down on a desk drops the teleop link within seconds.

Turn the proximity sensor off when you want the headset to keep running unworn, for example to:

- Run data collection with the control panel's [episode controls](/guides/control-panel#episode-controls).
- Watch the camera feeds in the control panel's [operator view](/guides/control-panel#operator-view), with the headset only tracking the controllers.
- Leave the VR app connected between takes.

## One-time setup

Turn on **Developer Mode** on the headset, as for [Quest over USB](/guides/quest-over-usb#one-time-setup). In the **Meta Quest** phone app, go to **Menu → Devices**, select your headset, then **Headset Settings → Developer Mode**. Turn it on and restart the headset.

## Keep the headset awake from the control panel

1. Plug the headset into the robot's computer with a USB-C cable.
2. If the headset shows **Allow USB debugging?**, accept it.
3. In the [control panel](/guides/control-panel#quest-usb), open the **Quest** tab under **General settings** and press **Keep awake**.

The display stays on and the VR session keeps running with the headset on a desk. You can unplug the cable afterwards. The headset stays awake until you press **Allow sleep** or restart the headset.

## Keep the headset awake with adb

The **Keep awake** and **Allow sleep** buttons run these `adb` commands on the robot's computer. [`axol provision`](/cli/provision) installs `adb`. With the headset plugged in, you can run them from any terminal:

```bash
# Disable the proximity sensor (keep the headset awake)
adb shell am broadcast -a com.oculus.vrpowermanager.prox_close

# Restore normal proximity behavior
adb shell am broadcast -a com.oculus.vrpowermanager.automation_disable
```

<Note>
  The setting is lost when the headset restarts. Run the command again, or press **Keep awake** again, after a restart.
</Note>

<Warning>
  With the sensor off, the display never sleeps. The battery drains at the full VR rate and the lenses keep projecting. Keep the headset on its charger for long sessions, and turn the sensor back on when you're done.
</Warning>

## Use Meta Quest Developer Hub instead

The [Meta Quest Developer Hub](https://developers.meta.com/horizon/documentation/unity/ts-odh/) desktop app has the same switch. Connect the headset over USB, open **Device Manager**, and turn off **Proximity Sensor**, or press `Ctrl+Shift+P`.

The app turns the sensor back on about 10 minutes after the headset disconnects from it, and you need it installed on a laptop. For a headset plugged into the robot, the control panel button works better.

## Run a session without wearing the headset

1. Open the VR app at [axol.almond.bot](https://axol.almond.bot) in the headset, connect to the robot, and press **Enter VR**.
2. Set the headset down. The controller poses and camera feeds keep streaming.
3. In the control panel, use the [episode controls](/guides/control-panel#episode-controls) to start, save and discard takes. Watch the camera feeds in the [operator view](/guides/control-panel#operator-view).

The controllers stay live the whole time, so an operator can pick them up at any point.
