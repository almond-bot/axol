---
title: "Offline updates"
description: "Update Axol from a downloaded file when the Host Computer has no internet access."
---

Every Axol release has an offline bundle for Host Computers that have no internet access. Download the bundle on any computer, copy it to the Host Computer and install it there. The install doesn't use the network.

<Note>
  The offline bundle updates an existing install. The Host Computer needs the [one-command install](/installation) once, with internet access.
</Note>

## Download the bundle

1. On a computer with internet access, open the [Axol releases page](https://github.com/almond-bot/axol/releases).
2. Under **Assets** for the release you want, download `axol-offline-v<version>-linux-aarch64.tar`. It is about 800 MB.
3. To check the download, also get the matching `.tar.sha256` file and run `sha256sum -c` on it.

The `linux-aarch64` bundle is for the Jetson Host Computers that Axol supports.

## Install the bundle

1. Copy the bundle to the Host Computer. Use a USB drive, or `scp` from a computer on the same network:

   ```bash
   scp axol-offline-v0.2.47-linux-aarch64.tar user@<host-ip>:
   ```

2. On the Host Computer, extract the bundle and run its installer:

   ```bash
   tar -xf axol-offline-v0.2.47-linux-aarch64.tar
   sudo ./axol-offline-v0.2.47-linux-aarch64/install
   ```

The installer does the following:

- Checks every file in the bundle. If a file is damaged, it stops before it changes anything.
- Installs the release and the Python packages it needs from the bundle.
- Installs the realtime control core, the camera streaming software and Lighthouse tracking from the bundle (see [`axol provision`](/cli/provision)).
- Restarts the `axol` service.

When it finishes, open `https://<host-ip>:8001` on a computer on the same network. The Host Computer serves the control panel and the [VR app](/guides/vr-interface) itself, so neither needs internet access. You can delete the `.tar` file and the extracted folder afterwards.

The control panel's update banner checks GitHub for releases, so it doesn't appear on a Host Computer without internet access. Install each release from its bundle instead.

## If the install stops

| Message | What to do |
|---|---|
| The bundle is damaged. | Copy the `.tar` file to the Host Computer again, then extract it again. |
| This bundle is for `<platform>`, but this computer is `<platform>`. | Download the bundle the message names. |
| Python 3.13 is not installed on this computer. | Run the [one-command install](/installation) once with internet access. Later updates can use the bundle. |

The bundle doesn't include the ZED SDK or Ubuntu packages. The install uses the copies already on the Host Computer. If an optional step needs something that isn't there, the install finishes with a warning that names the step. Axol works without it.
