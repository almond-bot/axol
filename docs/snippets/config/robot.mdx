| Flag | Default | Description |
|---|---|---|
| <F>--{prefix}left_stiffness</F> | `0.5` | How stiff the left arm is, from `0` (fully compliant) to `1` (rigid). One number applies to every joint; a 7-element list sets each joint in the order `shoulder_1, shoulder_2, shoulder_3, elbow, wrist_1, wrist_2, wrist_3`. Higher tracks targets more tightly but yields less to obstacles. |
| <F>--{prefix}right_stiffness</F> | `0.5` | Same, for the right arm. |
| <F>--{prefix}has_gripper</F> | `true` | Set `false` on the gripperless model. The gripper motors are never enabled and datasets record 7 channels per arm instead of 8. |
| <F>--{prefix}max_step_rad</F> | `0.5` | Largest joint move (rad) allowed between two consecutive commands. Bigger moves are dropped with a warning. `inf` disables. |
| <F>--{prefix}left.gripper.torque_limit</F> | `0.5` | Grip force — peak gripper torque (Nm). |
| <F>--{prefix}left.gripper.max_speed</F> | `10.0` | Maximum gripper speed (rad/s). |
| <F>--{prefix}left.elbow.kp</F> | per joint | Position stiffness of one joint at stiffness `0`, in `[0, 500]`. |
| <F>--{prefix}left.elbow.kd</F> | per joint | Velocity damping. Capped by the motor firmware (`5` on most motors); use `kd_soft` for more. |
| <F>--{prefix}left.elbow.kd_soft</F> | per joint | Extra software damping (Nm·s/rad) beyond the motor cap. |
| <F>--{prefix}left.elbow.j_eff</F> | per joint | Effective inertia (kg·m²) used for acceleration feed-forward. |
| <F>--{prefix}left.elbow.mass</F> | per joint | Mass (kg) of the link, used for gravity compensation. Tune if an arm sags or pushes back in [gravity comp](/operations/gravity-comp). |
| <F>--{prefix}left.elbow.com</F> | per joint | Centre of mass `[x, y, z]` (m) of the link. |
| <F>--{prefix}left.elbow.friction.fc</F> | per motor | Coulomb friction (Nm). Measured per motor with [`tune.friction`](/cli/tune-friction). |
| <F>--{prefix}left.elbow.friction.k</F> | per motor | Friction curve sharpness. |
| <F>--{prefix}left.elbow.friction.fv</F> | per motor | Viscous friction (Nm·s/rad). |
| <F>--{prefix}left.elbow.friction.fo</F> | per motor | Constant torque offset (Nm). |
